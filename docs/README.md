# Исследование кооператива для Casualties: Unknown

Дата среза: 23 ноября 2026 года.

Проект находится на этапе исследования. Цель — понять внутренние механики локальной сборки и подготовить план сетевого мода. По договорённости с пользователем реализация начинается после обсуждения документации.

## С чего продолжить

1. Начать с [актуальной спецификации кооператива](coop-plan.md). Для технического контекста использовать [разбор игровых систем](assembly-findings.md) и [разбор жидкостей](liquids.md). [Ранний проект](coop-design-draft.md) отражает первоначальные предположения до обсуждения требований.
2. Обсудить открытые игровые правила и проверить предположения из спецификации. В актуальном плане зафиксированы индивидуальный сон около 20 секунд без ускорения мира, выключаемый PvP, работа ловушек независимо от PvP и локальная физика игрока.
3. Если локальная сборка обновлялась, сверить SHA-256 игровой DLL и повторно проверить нужные классы и методы. Для повторной декомпиляции подходят `ilspycmd -p` и каталог `Managed` для разрешения зависимостей.
4. [Обзор механик](gameplay.md) и [первичный план разбора](code-review-plan.md) сохраняют исходные источники и вопросы. Новые выводы записывать с указанием класса, метода, версии или хеша и способа проверки.


5. [Разбор модов Together и Online](mod-reference-review.md) содержит решения для переподключения, сравнение реализаций и идеи механик.

6. [Свет и видимость](lighting-and-visibility.md) описывают локальное поле зрения, видимость чужих источников и проверки для кооператива.

7. [Дополнительные механики](additional-mechanics.md) включают часы мира, радиационную линию, переходы, станции и личный прогресс.

## Локальная сборка и инструменты

- Игровая сборка: `Casualties Unknown/CasualtiesUnknown_Data/Managed/Assembly-CSharp.dll`.
- Движок: Unity 2022.3.62f3, Windows x64, Mono. В папке игры есть управляемые DLL и `MonoBleedingEdge/`.
- SHA-256 игровой DLL: `48C7F2296FC4A659FAAE3B1822884CA5B7FF73D6767EF159E6A6C2BC0B2D38F1`.
- В `Lang/EN.json` указано `1.0.2`. Это версия файла локализации. Версию игрового билда следует подтвердить по метаданным самой игры или экрану меню.
- .NET SDK 10.0.404 доступен через `C:/Program Files/dotnet/dotnet.exe`. Команда `ilspycmd --version` вернула 11.2.0.10050.
- Изучены публичные источники и декомпилированные тела методов. Игровые сценарии и совместимость сторонних модов пока не проверялись запуском.
