# Журнал разработки кооператива

Начинай со [спецификации](coop-plan.md) и [инструкций сборки](../README.md). Репозиторий Git находится в `mode/`. История начинается с документов, исходники мода пишутся отдельно от игры и сторонних проектов.

## Состояние

- Стартовая реализация включает BepInEx-плагин и Steam-лобби на четыре места с приглашениями, никами, аватарками и готовностью.
- Рабочая и Steam-копия игры совпадают по SHA-256 игровой DLL из [индекса исследования](README.md). Steam-копия находится в `N:/Steam/steamapps/common/Casualties Unknown`.
- Проверь статус сборки и запуска по последней записи ниже. При работе из песочницы Git может потребовать `git -c safe.directory=N:/Projects/CU_mode/mode -C mode …` из корня рабочего пространства.

## Дальше

1. Подтвердить запуск плагина и создание/выход из приватной комнаты на одном Steam-аккаунте.
2. Проверить с двумя аккаунтами приглашение в открытой и закрытой игре, список, аватары и готовность. Затем проверить заполнение четырёх мест.
3. Добавить подтверждаемую связь с создателем комнаты, проверку совместимости игры и мода, персонажей по локальным разблокировкам и общую сложность.
4. Добавить запуск общего слоя через подтверждение хоста, передачу исходного состояния, подключение тела гостя и восстановление после обрыва. До реализации общего слоя кнопка запуска забега не подключается к одиночному запуску.
5. Продолжать по сценариям в спецификации. После каждого этапа записывать сделанное, проверки и следующий шаг, затем коммитить связанный набор изменений.

## Проверено на первом запуске

- Release-сборка прошла с 0 ошибками и 0 предупреждениями. BepInEx 5.4.23.5 в Steam-копии загрузил плагин и записал сообщение инициализации версии 0.1.0.
- Лог пока не подтвердил готовность Steam-лобби. Приватная комната, приглашения, аватары и готовность требуют проверки в главном меню. Steam-копию запустили командой из `scripts/Install-TestPlugin.ps1 -Launch`.
- NuGet-пакет эталонных сборок восстановлен в `mode/obj/nuget`. Для повторной сборки в песочнице установи `NUGET_PACKAGES` на этот каталог и используй `--no-restore`.
